# Проверочный лист Windows (по PDF, страницы 13, 16, 21–22, 27–30)

Статус каждого теста: `[ ]` не выполнялся на настоящем Windows/LocalDB.

## Сборка и инфраструктура

- [ ] Открыть `Tooded_EFCore.sln` в Visual Studio 2022; Framework `net8.0-windows`.
- [ ] Restore NuGet, Rebuild Solution — 0 ошибок, 0 отсутствующих зависимостей.
- [ ] Убедиться, что имеется `(localdb)\MSSQLLocalDB`.
- [ ] Запустить без БД `Tooded_DB`: появляются три таблицы и `__EFMigrationsHistory`, три начальные категории, два пользователя.
- [ ] После перезапуска данные остаются; миграции не повторяются.

## Tootehaldus — admin

- [ ] Войти `admin@admin.ee` / `admin123`, открыть Form2.
- [ ] Добавить товар без фото: успех, поле Pilt = NULL.
- [ ] Добавить товар с фото: копия в `%LOCALAPPDATA%\ToodedApp\Images`.
- [ ] Выбрать строку, изменить только цену, нажать Uuenda: категория и картинка остаются.
- [ ] Проверить поля `abc`, `-2`, пустое название: выводится сообщение, приложение не падает.
- [ ] Удалить выбранный товар, проверить отсутствие в SQL.
- [ ] Удаление при отсутствии выделенной строки не вызывает исключения.

## Pood и Ostukorv

- [ ] Появляется одна вкладка на категорию и карточки всех товаров.
- [ ] Для товара с Kogus=0 кнопка «Lisa korvi» неактивна.
- [ ] Добавить товар в корзину; закрыть Form3, открыть ArveForm: корзина сохранилась.
- [ ] Повторным добавлением нельзя превысить Kogus на карточке.
- [ ] После изменения остатков в БД перед покупкой срабатывает финальная SQL-проверка.
- [ ] Удалить одну строку из корзины и проверить сумму.

## PDF и e-post

- [ ] Продать 2 товара: PDF появляется в `%LOCALAPPDATA%\ToodedApp\Arved`.
- [ ] В PDF верны названия, количество, цены, дата и общая сумма.
- [ ] В SQL уменьшилось количество каждого купленного товара ровно на число покупок.
- [ ] В случае ошибки PDF/SQL не должно остаться частично списанного заказа.
- [ ] Послать PDF на собственную почту, проверить наличие вложения.
- [ ] Без SMTP-переменных приложение даёт понятное сообщение и не раскрывает пароль.

## MSI (только Windows)

- [ ] Создать MSI с Visual Studio Installer Projects либо Build-MSI.ps1.
- [ ] Установить на чистую Windows x64 VM с установленным SQL Server Express LocalDB.
- [ ] Запустить через ярлык, войти и проверить то же тестирование форм, PDF, e-mail.
- [ ] Удалить приложение через Settings → Apps.

Ни один из пунктов нельзя пометить успешным без фактического выполнения.
