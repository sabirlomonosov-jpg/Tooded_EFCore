# Меню McDonald’s · Эстония

Приложение использует красно-жёлтую палитру, золотые арки, белые карточки блюд и категории меню. Обновлены каталог, вход, главное меню и общий стиль управления товарами и корзины. Это учебный интерфейс, вдохновлённый McDonald’s.

## Товары, цены и изображения

17 позиций. **Цены примерные в евро**, их нельзя считать актуальными ценами ресторанов Эстонии: официальный сайт недоступен из этой среды. Названия и комплектации также требуют проверки по меню конкретного ресторана. Администратор может менять цены в приложении.

## Применение к базе

На Windows с установленной SQL Server Express LocalDB откройте решение в Visual Studio или выполните из корня репозитория:

```powershell
dotnet run --project Tooded_EFCore/Tooded_EFCore.csproj
```

`Program.Main` вызывает `Database.Migrate()`. Новая миграция `20261030000100_McDonaldsMenu` выполняется один раз и работает как на новой базе, так и на существующей `Tooded_DB`:

- заменяет 17 старых демонстрационных продуктов, сравнивая их точные имена;
- сохраняет ID и остатки заменяемых строк, меняет название, цену, категорию и ссылку на изображение;
- добавляет отсутствующие блюда с учебным остатком 25;
- не меняет учётные записи и остальные товары;
- не сбрасывает изменённые администратором цены и остатки при повторном запуске.

Если новое блюдо с таким именем уже существует, его строка сохраняется, а старый демонстрационный дубликат удаляется. Продукт со старым демонстрационным именем будет заменён даже при ранее изменённых вручную цене или фотографии. Перед обновлением существующей базы сохраните резервную копию. Автоматический откат меню намеренно не поддерживается: прежние цены и фотографии не восстанавливаются из кода. Для отката нужна резервная копия базы.

Здесь миграция **не применялась к живой базе**: Linux не поддерживает Windows Forms и LocalDB.

## Корзина в магазине и запуск базы

Справа в магазине появился чек: названия, цены за единицу, количество, суммы строк и общий итог. Количество можно редактировать; 0 или × удаляют позицию. Пустой заказ или превышение остатков блокируют переход к оплате. «Edasi maksma» открывает существующий сценарий подтверждения покупки и создания PDF; внешняя платёжная система не подключалась. После возврата из оплаты корзина и остатки обновляются. «Värskenda» также обновляет цены и наличие товаров в чеке.

`AndmebaasiAlgataja.Valmista` теперь проверяет наличие базы через `master` и создаёт её только при отсутствии. Серверная блокировка предотвращает одновременное выполнение подготовки двумя экземплярами. Существующая база открывается до вызова миграций, чтобы ошибка доступа не трактовалась как отсутствие базы. Ошибка SQL Server 1801 при создании другим клиентом обрабатывается открытием уже созданной базы. База не удаляется и не переименовывается. Несовместимая старая схема без корректной истории миграций требует ручной диагностики; приложение не создаёт фиктивную историю миграций.

По умолчанию остаётся `(localdb)\\MSSQLLocalDB`, база `Tooded_DB`. Для отдельной новой базы можно явно задать строку подключения до запуска приложения, например в PowerShell:

```powershell
$env:TOODED_CONNECTION_STRING = 'Server=(localdb)\MSSQLLocalDB;Database=Tooded_McDonalds_DB;Trusted_Connection=True;Encrypt=False;'
dotnet run --project Tooded_EFCore/Tooded_EFCore.csproj
```

Это создаст отдельную базу, а не перенесёт данные из старой. Не меняйте подключение, если нужно продолжить работать с прежними данными. При запуске из Visual Studio переменная должна быть доступна её процессу.

После добавления чека выполнены Release-сборка, 20/20 проверок меню, генерации SQL и поведения корзины, 71/71 статическая проверка. Проверки на живом SQL Server добавлены, но не выполнялись: загрузка тестового контейнера блокируется сетевым запретом для `westus.data.mcr.microsoft.com`. Windows Forms и ошибку на конкретном Windows-компьютере здесь воспроизвести нельзя. Ручные сценарии описаны в `TEST_PLAN_RU.md`.

## Временные сбои LocalDB при запуске

Запуск теперь делает до трёх попыток только при распознанных временных сбоях подключения (паузы 1 и 2 секунды). Каждая попытка использует новый контекст EF; пул неудачного подключения очищается. Повтор охватывает подготовку базы и начальные данные. Глобальный `EnableRetryOnFailure` намеренно не включён: покупка и добавление меню используют явные транзакции и не должны автоматически повторяться вместе с созданием PDF.

Если запуск всё равно не удался, сообщение показывает вложенную причину и номер ошибки SQL Server вместо одной общей рекомендации `EnableRetryOnFailure`. По общей рекомендации нельзя заключить, что сбой действительно временный: причина может быть в доступе, состоянии базы или LocalDB. Существующая база не удаляется. Если проблема остаётся после пересборки, для диагностики нужен полный новый текст с номером SQL Server.

Проверки: Release-сборка, 26/26 проверок меню/корзины/повторов и 71/71 статическая проверка прошли. Подтверждения устранения сбоя на конкретном Windows-компьютере пока нет.

## Восстановление после ошибок 4060 / 18456

Эти ошибки означают, что текущее подключение не может открыть выбранную базу. При запуске больше нет повторных попыток для этих ошибок. `Encrypt=False` остаётся в настройках LocalDB; изменение шифрования не выдаёт права доступа.

Для стандартного LocalDB-подключения без заданной `TOODED_CONNECTION_STRING` окно ошибки предлагает **«Loo eraldi uus andmebaas»** — создать отдельную новую базу. Нажатие явно выбирает новый магазин с начальным меню и демонстрационными учётными записями. Старая база не удаляется, не переименовывается и не изменяется; её товары и пользователи не переносятся. Если нужны прежние данные, закройте окно и восстановите доступ к старой базе через её владельца или администратора.

Имя новой базы имеет вид `Tooded_App_<уникальный идентификатор>`. После успешного создания, миграций и заполнения имя сохраняется в `%LOCALAPPDATA%\ToodedApp\database-name.txt`. Все последующие окна и повторные запуски используют выбранную базу. Файл содержит только имя, без паролей и полной строки подключения. При отмене или неудачном запуске новый выбор не сохраняется. Ранее заданная `TOODED_CONNECTION_STRING` имеет приоритет и не меняется через окно восстановления. Проблемы с самим экземпляром LocalDB или правом создания баз эта кнопка не исправляет; при ошибке остаётся доступен её полный текст.

Проверено: Release-сборка, 34/34 проверки логики и 71/71 статическая проверка. Фактический запуск восстановления на Windows LocalDB здесь не выполнялся.
