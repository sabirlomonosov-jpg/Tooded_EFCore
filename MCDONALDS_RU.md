# Меню McDonald’s · Эстония

Приложение использует красно-жёлтую палитру, золотые арки, белые карточки блюд и категории меню. Обновлены каталог, вход, главное меню и общий стиль управления товарами и корзины. Это учебный интерфейс, вдохновлённый McDonald’s.

## Товары, цены и изображения

17 позиций. **Цены примерные в евро**, их нельзя считать актуальными ценами ресторанов Эстонии: официальный сайт недоступен из этой среды. Названия и комплектации также требуют проверки по меню конкретного ресторана. Администратор может менять цены в приложении.

Изображения созданы ИИ для проекта, это не официальные фотографии. Атлас `Tooded_EFCore/Assets/menu-atlas.png` содержит 16 иллюстраций; средняя и большая порции картофеля используют одну иллюстрацию. Он включён в сборку и публикацию. При запуске изображения извлекаются в `%LOCALAPPDATA%\ToodedApp\Images`, после чего доступны без интернета. ## Применение к базе

На Windows с установленной SQL Server Express LocalDB откройте решение в Visual Studio или выполните из корня репозитория:

```powershell
dotnet run --project Tooded_EFCore/Tooded_EFCore.csproj
```

`Program.Main` вызывает `Database.Migrate()`. Новая миграция `20261030000100_McDonaldsMenu` выполняется один раз и работает как на новой базе, так и на существующей `Tooded_DB`:

- заменяет 17 старых демонстрационных продуктов, сравнивая их точные имена;
- сохраняет ID и остатки заменяемых строк, меняет название, цену, категорию и ссылку на изображение;
- добавляет отсутствующие блюда с учебным остатком 25;
- не меняет учётные записи и остальные товары;
- не сбрасывает изменённые администратором цены и остатки при повторном запуске.

Если новое блюдо с таким именем уже существует, его строка сохраняется, а старый демонстрационный дубликат удаляется. Продукт со старым демонстрационным именем будет заменён даже при ранее изменённых вручную цене или фотографии. Перед обновлением существующей базы сохраните резервную копию. Автоматический откат меню намеренно не поддерживается: прежние цены и фотографии не восстанавливаются из кода. Для отката нужна резервная копия базы.

Здесь миграция **не применялась к живой базе**: Linux не поддерживает Windows Forms и LocalDB.

## Проверки

```sh
dotnet build Tooded_EFCore.sln -c Release --no-restore
dotnet run --project Tests/MenuChecks/MenuChecks.csproj
python3 Tests/validate_project.py
dotnet publish Tooded_EFCore/Tooded_EFCore.csproj -c Release --no-restore -o /tmp/tooded-mcd-publish
```

Результаты: Release-сборка и обычная публикация успешны; 9/9 проверок меню и генерации SQL Entity Framework прошли; 71/71 статическая проверка прошла. Исправлены устаревшие проверки, требовавшие отдельные Designer-файлы вместо уже существующего программного построения форм. Контрольные суммы атласа в исходниках, сборке и публикации совпадают. Сохраняется прежнее предупреждение CS8669 в `.Designer.cs`.

Проверки SQL не подключаются к LocalDB и не доказывают применение миграции на сервере. На Windows остаётся проверить: первое обновление существующей базы, повторный запуск без сброса цены/остатка, наличие изображений у всех блюд, изменение размера окна, поиск и категории, покупку и PDF по `TEST_PLAN_RU.md`. MSI и отправка email в этой задаче не проверялись.
